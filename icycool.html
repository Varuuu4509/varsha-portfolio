ICY COOL

LABEL DESIGN · VISUAL IDENTITY · FLAVOUR SYSTEM

Icy Cool is an ice cream label design project focused on strong shelf appeal and clear flavour differentiation. Distinct colour palettes, product imagery and clean typography create an engaging and easily recognisable visual system.

THE LABEL SYSTEM

IN-MOULD LABEL (IML) · VISUAL IDENTITY · FLAVOUR SYSTEM

Designed as an in-mould label (IML) system for ice cream tubs, each flavour uses a distinct colour palette and product imagery for clear differentiation, while consistent typography and layout create a cohesive visual identity across the range.
